Kubernetes kind values

Every Kubernetes YAML says what object it creates with kind, and which API group and version it belongs to with apiVersion. The two always go together:

apiVersion: apps/v1
kind: DaemonSet
ClusterIP is not a kind. It is a value of spec.type inside a Service. See the last section for the values that look like kinds but aren't.

Columns: apiVersion to write in the YAML, short name for kubectl (for example kubectl get ds), and NS: whether the object lives in a namespace (yes) or is cluster-wide (no). The list comes from kubectl api-resources on the local minikube cluster (Kubernetes v1.34).

Workloads: run containers

kindapiVersionshort · NSWhat it is
Podv1po · yesOne or more containers that run together on one node. The smallest thing Kubernetes runs.
Deploymentapps/v1deploy · yesKeeps N copies of a stateless pod running and does rolling updates. The usual choice for apps.
ReplicaSetapps/v1rs · yesKeeps N identical pods running. A Deployment creates these for you.
StatefulSetapps/v1sts · yesPods with stable names (db-0, db-1) and their own disks. For databases, Kafka, etc.
DaemonSetapps/v1ds · yesOne pod on every node. Used for CNI (kindnet), kube-proxy, log and monitoring agents.
Jobbatch/v1— · yesRuns pods until a task finishes successfully, then stops.
CronJobbatch/v1cj · yesCreates a Job on a schedule, like cron.
ReplicationControllerv1rc · yesThe old version of ReplicaSet. Don't use it in new YAML.
PodTemplatev1— · yesA saved pod definition. Rarely written by hand.
ControllerRevisionapps/v1— · yesHistory of a StatefulSet or DaemonSet, used for rollbacks. Created automatically.

EndpointSlicediscovery.k8s.io/v1— · yesThe newer, scalable form of Endpoints. Created automatically.
ServiceCIDRnetworking.k8s.io/v1— · noThe IP range Service IPs are taken from.
IPAddressnetworking.k8s.io/v1ip · noRecords one Service IP as in use. Created automatically.

Not kinds, but often confused with them

These go in a type or other field inside an object, never in kind.

FieldValues
Service → spec.typeClusterIP (default, inside the cluster only), NodePort (a port on every node), LoadBalancer (a cloud load balancer), ExternalName (a DNS alias). clusterIP: None makes a headless Service.
Secret → typeOpaque (default), kubernetes.io/tls, kubernetes.io/dockerconfigjson, kubernetes.io/basic-auth, kubernetes.io/ssh-auth, kubernetes.io/service-account-token
NetworkPolicy → spec.policyTypesIngress, Egress
Deployment → spec.strategy.typeRollingUpdate (default), Recreate
Pod → spec.restartPolicyAlways, OnFailure, Never
Container → imagePullPolicyAlways, IfNotPresent, Never
PVC → accessModesReadWriteOnce, ReadOnlyMany, ReadWriteMany, ReadWriteOncePod

Find the kinds on any cluster

kubectl api-resources                    # every kind, its apiVersion and short name
kubectl api-resources --namespaced=false # only cluster-wide kinds
kubectl api-resources --api-group=apps   # one API group
kubectl explain daemonset.spec           # the fields a kind accepts
kubectl get crd                          # kinds added by installed tools
