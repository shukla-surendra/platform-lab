rust-sqlite-api

An OTLP collector on embedded SQLite, doubling as a public API-testing target.

Everything under /api/test/* is stateless. Nothing there touches the database or perturbs the telemetry counters, so it can be hammered freely — point a load generator, a client library, an ingress rule, or a probe at it.

Health & identity

GET/healthz Liveness. Never touches the database — a liveness probe that fails on a busy DB restarts the pod, which unlocks nothing.
GET/readyz Readiness. Does query the database, because an instance that cannot reach storage should leave the Service, not be killed.
GET/version Which binary is actually answering. First call when a deployment "didn't take".
GET/metrics Prometheus text. The collector's own health, not the telemetry it stores.

API testing (stateless)

GETPOST/api/test/echo Echoes method, path, query, headers and body. Answers what was actually sent.
GET/api/test/status/{code} Returns that status. For retry logic and alert rules against real codes.
GET/api/test/delay/{ms} Sleeps, then responds. Capped at 30s.
GET/api/test/uuid A v4 UUID.
GET/api/test/headers Request headers as this server received them.
GET/api/test/ip Peer address plus forwarding headers. Behind a proxy the peer is the proxy — that gap is the point.
GET/api/test/bytes/{n} Deterministic payload of n bytes, capped at 10 MB. Same bytes every time, so runs are comparable.
GET/api/test/json A fixed-shape document for deserialisation tests.

Observability pipeline

POST/debug/logstorm?count=500&tag=x Emits a known number of log lines at known levels, and reports exactly how many were emitted vs suppressed by RUST_LOG. Compare that against Loki to prove the pipeline loses nothing.

OTLP ingest

POST/v1/logsOTLP/HTTP JSON.
POST/v1/metricsGauge, sum, histogram.
POST/v1/tracesSpans; re-delivery is deduped.
OTEL_EXPORTER_OTLP_ENDPOINT=http://<host>:8080
OTEL_EXPORTER_OTLP_PROTOCOL=http/json   # not gRPC

Query stored telemetry

GET/api/summary Row counts and known services. Separates "nothing sent" from "sent wrong".
GET/api/logs ?service= &severity= &trace_id= &q= &since= &until= &limit=
GET/api/metrics ?name= &service= &kind= &since= &until= &limit=
GET/api/traces ?service= &min_duration_ms= &since= &limit=
GET/api/traces/{trace_id} Assembled span tree with per-span offsets.
