rust-api

A small, public, stateless HTTP server for testing clients against — a health check, a way to generate log lines on demand, and a handful of predictable request/response endpoints.

Nothing here is stored. No database, no file, no memory between requests except a request counter used only in the heartbeat log line. Every response is derived entirely from the request that produced it — hammer any endpoint as hard as you like. This same table, as JSON: /api/endpoints.
