# Terraform: Azure SQL Database (minimal)

RG + a logical SQL Server + one Basic-tier database + a firewall rule
allowing Azure-internal access. Admin password is generated by Terraform
(`random_password`), not hardcoded or supplied by you.

> ⚠️ **This creates billable resources.** Basic tier is the cheapest SKU
> (~$5/month) but it's not free, and it bills for existing, not for usage.
> Run `terraform destroy` when done.

## Usage

```bash
terraform init
terraform apply
```

To connect from your own machine, first add your IP as a firewall rule
(not included by default -- see "What's deliberately not here"):

```bash
az sql server firewall-rule create \
  --resource-group rg-sql-demo \
  --server $(terraform output -raw sql_server_fqdn | cut -d. -f1) \
  --name AllowMyIP \
  --start-ip-address <your-ip> --end-ip-address <your-ip>
```

Then connect with any SQL client using `sql_server_fqdn`, `admin_login`
(`sqladmin`), and `terraform output -raw admin_password`.

## What's deliberately not here

No firewall rule for your own client IP (added manually above, since it's
different for every learner and every network) -- only the `0.0.0.0` special
case Azure documents as meaning "allow other Azure services," which is
easy to misread as "allow the whole internet" and isn't. No elastic pool,
no auditing/threat detection, no private endpoint, no read replica.

## Teardown

```bash
terraform destroy
```
