# Terraform: Azure Linux VM (minimal)

Smallest self-contained VM you can SSH into: RG, VNet/subnet, public IP,
NSG (SSH only), NIC, and an `Standard_B1s` Ubuntu 22.04 VM. The SSH keypair
is generated by Terraform itself -- no pre-existing key required.

> ⚠️ **This creates billable resources** -- the VM, its Standard public IP,
> and its disk all cost money while they exist (Standard_B1s is eligible
> for the Azure free-tier 750 hrs/month if you still have that). Run
> `terraform destroy` when done. `terraform plan` alone costs nothing.

## Usage

```bash
terraform init
terraform apply
```

Get the SSH key and connect:

```bash
terraform output -raw ssh_private_key > vm_key.pem
chmod 600 vm_key.pem
ssh -i vm_key.pem azureuser@$(terraform output -raw public_ip_address)
```

## What's deliberately not here

No data disk, no availability zone/set, no boot diagnostics, no
auto-shutdown schedule, no custom cloud-init script. NSG allows SSH from
anywhere (`0.0.0.0/0`) for zero-friction first use -- narrow
`source_address_prefix` in `main.tf` to your own IP before leaving this up
for longer than a quick test.

## Teardown

```bash
terraform destroy
```
