# 009 – Smallest RDS (PostgreSQL) + RDS Proxy

`db.t4g.micro` PostgreSQL 16, 20 GB gp3, private (not publicly accessible), fronted by an RDS Proxy.

- Master password is generated by RDS into Secrets Manager (`manage_master_user_password`), so it never appears in Terraform state.
- Proxy reads that secret via an IAM role (`rds.amazonaws.com`).
- DB security group only allows 5432 from the proxy; the proxy allows 5432 from the VPC.
- Needs subnets in >= 2 AZs (default VPC has them).

```
terraform init
terraform plan      # review first
terraform apply     # takes ~5-10 min (RDS + proxy)
terraform destroy   # right after practice
```

Connect: from an instance in the VPC (e.g. the 008 SSM instance) use the `proxy_endpoint` output
with a psql client and TLS; get the password from the secret in `secret_arn`.

Cost warning: RDS Proxy is billed per vCPU-hour of the DB (min 2 vCPUs, ~ $22/month) on top of the
instance. Destroy when done.
