# 30/60/90-Day Communication Challenges

Three structured programs of increasing length, each sequencing the rest of this repository into a concrete, dated plan. Pick the length based on how much runway you have before a specific goal (a promotion cycle, an interview loop, a big presentation) — or run the 90-day version as the default deep program.

---

## The 30-Day Challenge: Foundation + Fluency

**Goal:** install the core frameworks and phrase library as automatic reflexes. This is diagnostic-and-installation, not mastery — expect real but modest visible change by day 30.

```
WEEK 1 — DIAGNOSE
  Day 1-2:  Read 01_Foundations in full. Record 3 baseline explanations
            (no framework, just talk) before reading further — this is
            your "before" reference for later comparison.
  Day 3-7:  Daily Practice routine (10_Daily_Practice) begins. Focus:
            Answer-First Reps (Block 2) + one recorded rep/day.
            Weekly review using 12_Recording_Analysis/02 checklist.

WEEK 2 — INSTALL PREP + PHRASE LIBRARY
  Read 03_Explanation_Frameworks/01 (PREP section) and
  05_Phrase_Library/01-02 in full.
  Daily: PREP reflex drill (11_Exercises/1.4), 10 reps/day.
  Daily: phrase recall warm-up from 05_Phrase_Library.

WEEK 3 — INSTALL STAR + SCQA
  Read 03_Explanation_Frameworks/01 (STAR/SCQA) in full.
  Build your first 3 story-bank entries (08_Interview_Communication/01).
  Daily: alternate STAR/SCQA practice using real stories from your work.

WEEK 4 — APPLY + MEASURE
  Read 13_Common_Mistakes in full — identify your top 2 recurring
  patterns from 4 weeks of recordings.
  Do one Tier 2 exercise (11_Exercises) daily.
  Day 30: record the SAME 3 baseline explanations from Day 1-2.
  Compare directly — this is your most important artifact from the
  30-day program.
```

**Day 30 success check:** can you produce a clean PREP answer to an unprompted question with under 5 seconds of visible hesitation? Can you name your own top 2 recurring mistakes specifically (not vaguely)?

## The 60-Day Challenge: Foundation + Domain Application

**Goal:** everything in the 30-day challenge, plus applying it fluently to your specific technical domain (architecture communication, incident communication, interview readiness).

```
DAYS 1-30    Run the full 30-Day Challenge above.

WEEK 5 — ARCHITECTURE COMMUNICATION
  Read 07_Architecture_Communication in full.
  Do one real architecture walkthrough (a real system you own) using
  the full framework, recorded, 5+ minutes.
  Get a real colleague to run a mini design-review pass on it if possible.

WEEK 6 — STORYTELLING + INCIDENTS
  Read 04_Technical_Storytelling in full.
  Rewrite 2 of your story-bank entries with the full 4-beat arc,
  specifically adding a genuine tension beat if missing.
  If you have a real recent incident, write a full postmortem using
  the template in 09_Meeting_Communication/01.

WEEK 7 — INTERVIEW READINESS
  Read 08_Interview_Communication in full.
  Build out your full story bank to 6-8 entries
  (14_Advanced/01 template).
  Run one full mock system design interview, solo, recorded, 30-45 min
  (11_Exercises/3.1).

WEEK 8 — STRESS TEST
  Apply a specific framework deliberately in 3 real meetings this week
  (not practice — actual work meetings) and debrief each one same-day
  in your training log.
  Day 60: full checklist review (12_Recording_Analysis/02) on a real
  meeting recording if you have one, or a fresh solo recording
  otherwise.
```

**Day 60 success check:** have you used a framework from this repo, deliberately and noticeably, in at least 5 real meetings? Can you complete a 30-minute system design narration without losing structure?

## The 90-Day Challenge: Full Mastery Program

**Goal:** the complete repository, applied, measured, and beginning to compound — by day 90 the frameworks should feel less like a checklist and more like how you naturally think.

```
DAYS 1-60    Run the full 60-Day Challenge above.

WEEK 9 — ADVANCED STORYTELLING + EXECUTIVE COMMUNICATION
  Read 06_Project_Presentation and 05_Phrase_Library/05 in full.
  Write one full executive summary for a real project (06/01 template).
  Practice the Compression Ladder (11_Exercises/3.6) on 3 different
  real stories.

WEEK 10 — CASE STUDY BUILDING
  Read 14_Advanced/01 in full.
  Build 2 full case studies from your own real work using the
  Reusable Case Study Template.
  These become permanent interview/promotion-packet assets, not
  just exercises.

WEEK 11 — MOCK PRESSURE TESTS
  Run one full mock behavioral interview loop (8 questions,
  11_Exercises/3.2), ideally with a real practice partner giving
  live feedback, not solo.
  Run one full mock design review as both presenter AND reviewer
  (07_Architecture_Communication/01) — reviewing others sharpens your
  own presenting instincts.

WEEK 12 — CONSOLIDATE + PLAN THE NEXT CYCLE
  Full 90-day recording comparison: Day 1 baseline vs. Day 90.
  Re-read 13_Common_Mistakes — which mistakes have genuinely resolved,
  which are still recurring?
  Set the next 90-day focus — likely a narrower, harder skill
  (e.g., executive presence specifically, or a live interview loop)
  rather than repeating the full breadth again.
```

**Day 90 success check:** run through the full Tier 3 self-assessment in `11_Exercises/01` — every box should be checkable. If not, that's not a failure of the program; it's a signal for what Week 13 onward should focus on.

## Rules That Apply to All Three Challenges

1. **Missing a day doesn't reset the challenge.** Continue from where you are — consistency over a long window matters more than an unbroken streak (this mirrors the spaced-repetition logic in `10_Daily_Practice`, not an all-or-nothing mindset).
2. **The Day 1 baseline recording is mandatory, not optional.** Without it, you have no way to see progress objectively — day-to-day change is invisible; 30/60/90-day change usually isn't, but only if you have the comparison point.
3. **Real-meeting application matters more than solo drilling past Week 4.** Solo practice builds the reflex; real meetings are where it either transfers or doesn't, and only real application reveals which frameworks need more reps.
4. **Don't skip the reflection weeks (4, 8, 12).** They're not filler — they're what turns scattered practice into a compounding skill by identifying what to focus on next.

## Glossary — Vocabulary Used in This Chapter

| Term / Phrase | Meaning |
|---|---|
| **Runway** | The amount of time available before a deadline or goal, borrowed from an aircraft's takeoff distance. |
| **Compound** (verb) | To build up or intensify over time through repeated, cumulative effect. |
| **Filler** | Non-essential content included mainly to pad length, rather than adding real value. |
| **Install** (a skill/reflex) | To build a behavior into someone so thoroughly it becomes automatic, as if added to a system. |
| **All-or-nothing** (mindset) | The belief that anything short of total, unbroken consistency counts as failure. |
| **Unprompted** | Done without being asked or cued — initiated on one's own. |
| **Mock** | A practice version of a real event, designed to closely simulate it without the actual stakes. |
