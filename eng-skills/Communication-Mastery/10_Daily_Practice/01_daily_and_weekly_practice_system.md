# Daily Practice System

Per the testing-effect research in `01_Foundations/02`, reading this repository builds almost no durable skill on its own. This chapter is the training system — a structured 45–60 minute daily routine, plus a weekly rhythm, that converts the frameworks and phrases into automatic behavior.

## Why Daily, and Why This Specific Structure

Communication skill decays fast without use — faster than most technical skills, because it's an *output* skill (production, not recognition) and output skills need active retrieval practice to stay sharp (`01_Foundations/02`). A once-a-week 3-hour session is measurably worse than six 30-minute daily sessions covering the same total time, because spaced repetition with retrieval beats massed practice for durable retention. Daily, shorter sessions are the correct shape, not a compromise.

## The 45–60 Minute Daily Routine

```
┌──────────────────────────────────────────────────────────────┐
│ BLOCK 1 — WARM-UP (5 min)                                       │
│ Phrase recall: pick 2 sections from 05_Phrase_Library,          │
│ read 10 phrases aloud, then close the file and produce 10       │
│ from memory using a real fact about your current work. Fold in  │
│ 2-3 Active Rotation items from the vocabulary lexicon system    │
│ (../../Vocabulary-Collections/surface-vs-deep-lexicon.md §6).   │
├──────────────────────────────────────────────────────────────┤
│ BLOCK 2 — ANSWER-FIRST REPS (10 min)                             │
│ 10 reps of the Answer-First Reflex Drill                        │
│ (02_Thinking_Frameworks/01) — 10-second timer, one-sentence      │
│ answer, then full PREP expansion.                                │
├──────────────────────────────────────────────────────────────┤
│ BLOCK 3 — FRAMEWORK ROTATION (15 min)                            │
│ Rotate daily: Mon/Thu = PREP, Tue/Fri = STAR, Wed = SCQA,         │
│ Sat = Pyramid Principle, Sun = free choice / weak-spot focus.    │
│ Pick a real fact or story, produce the full framework out loud,  │
│ timed. Use 11_Exercises for a deep bank of prompts.               │
├──────────────────────────────────────────────────────────────┤
│ BLOCK 4 — RECORDED REP (10 min)                                  │
│ Record ONE explanation, 60-90 seconds, on your phone or          │
│ laptop. Vary the topic daily — pull from your actual current      │
│ work (a system, a decision, an incident). This is the highest-    │
│ leverage block — see 12_Recording_Analysis for review method.    │
├──────────────────────────────────────────────────────────────┤
│ BLOCK 5 — REVIEW (10 min)                                        │
│ Watch/listen back to Block 4's recording using the Self-Review   │
│ Checklist (12_Recording_Analysis/02). Note ONE specific thing     │
│ to fix tomorrow — not five, one, so it's actually actionable.     │
├──────────────────────────────────────────────────────────────┤
│ BLOCK 6 — LOG (5 min)                                            │
│ Update your training log (template below). This is what turns    │
│ 12 weeks of scattered practice into a visible trend.              │
└──────────────────────────────────────────────────────────────┘
```

**If you only have 20 minutes some days:** do Block 2 (Answer-First Reps) and Block 4+5 (Recorded Rep + Review) only. These two blocks have the highest return per minute — everything else is valuable but more compressible.

## Weekly Structure

```
MONDAY     Full 60-min routine. Framework focus: PREP.
TUESDAY    Full 45-min routine. Framework focus: STAR.
WEDNESDAY  Full 45-min routine. Framework focus: SCQA.
THURSDAY   Full 60-min routine. Framework focus: PREP (harder prompts —
           pull from 11_Exercises' higher-difficulty tier).
FRIDAY     Full 45-min routine. Framework focus: STAR (interview-style,
           use 08_Interview_Communication prompts).
SATURDAY   Lighter — 30 min. Pyramid Principle or a written exercise
           (draft an SCQA-opened design doc section for real work).
SUNDAY     Review week. Re-watch your best AND worst recording from
           the week. Update the weekly section of your training log.
           Pick next week's weak-spot focus based on the pattern you
           see (13_Common_Mistakes helps name what you're seeing).
```

## Monthly Rhythm

- **Week 1 of the month:** heavier focus on `05_Phrase_Library` — building raw vocabulary fluency.
- **Week 2:** heavier focus on `07_Architecture_Communication` and `08_Interview_Communication` — applying frameworks to your actual technical domain.
- **Week 3:** heavier focus on `04_Technical_Storytelling` — narrative and memorability.
- **Week 4:** stress-test week — do a real explanation in a real meeting deliberately using a framework you've drilled, then debrief it in Block 5/6 the same day. This is where practice starts transferring to real outcomes; see `14_Advanced/02_challenges_30_60_90.md` for structured multi-week programs built on this rhythm.

## Training Log Template

Copy this into a notes doc, journal, or tracking tool, and fill it in daily (Block 6) and weekly (Sunday).

```markdown
## Daily Log — [date]

Framework drilled: ____________
Recorded topic: ____________
One thing to fix tomorrow: ____________
Real-meeting application today? (Y/N, and what happened): ____________

## Weekly Log — Week of [date]

Frameworks drilled this week: ____________

Worst recording this week (what specifically went wrong): ____________

Next week's focus: ____________
Real-meeting wins (a phrase/structure that landed): ____________
```

## Why "Recorded Rep" Is Non-Negotiable

It's tempting to skip Block 4 — talking to a phone camera feels artificial compared to "just practicing in my head." Resist this. Silent or in-head rehearsal doesn't produce the same signal as spoken output, because speaking recruits motor planning and real-time compression under a (mild, self-imposed) social-evaluative load that silent rehearsal doesn't (`01_Foundations/02`). The discomfort of watching yourself back is itself part of the training — it's building tolerance for the exact discomfort that causes stalls in real meetings, in a low-stakes, repeatable setting.

## Glossary — Vocabulary Used in This Chapter

| Term / Phrase | Meaning |
|---|---|
| **Non-negotiable** | Not open to compromise or exception — treated as mandatory regardless of circumstance. |
| **Massed practice** | Concentrating all practice into one long session, as opposed to spreading it out over time (contrasted with spaced repetition). |
| **Recruit** (a mechanism) | To engage or activate a physical or cognitive process as part of performing an action. |
| **Self-imposed** | A pressure or constraint created by oneself rather than applied from outside. |
| **Stall** | A moment of being unable to continue speaking or thinking, breaking the momentum of an explanation. |
| **Highest-leverage** | Producing the greatest return relative to the time or effort invested. |
| **Compressible** | Able to be shortened or reduced in scope without losing its essential value. |
| **Debrief** | To review and discuss an event immediately after it happens, extracting lessons from it. |
| **Stress-test** | To deliberately push something to its limits to see how it holds up under real pressure. |
